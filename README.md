## ⚡ The Problem It Solves

Many new store owners face a frustrating dilemma when setting up WooCommerce:
- **Clunky Cart Flows:** By default, adding a product to the cart often reloads the entire page or takes shoppers away from the product they were exploring.
- **Lost Buy Buttons on Mobile:** As shoppers scroll down to read reviews, benefits, and ingredients, the purchase button disappears off-screen.
- **Theme Bloat:** Typical commercial themes ship with dozens of unused plugins and complex sliders that slow down mobile loading times and complicate store management.

**ApexCommerce** provides a lightweight, modular foundation built directly on WooCommerce standards. It delivers the fast, modern experience shoppers expect from leading direct-to-consumer brands while keeping the codebase clean and easy to maintain.

---

## 🛠️ Key Storefront Features

- **Slide-Out AJAX Cart Drawer:** Updates instantly when items are added, keeping customers immersed in your catalog.
- **Free-Shipping Progress Meter:** Shows shoppers how close they are to qualifying for free delivery to encourage higher order values.
- **Sticky Purchase Bar:** Stays conveniently accessible as shoppers scroll down long product descriptions on mobile and desktop.
- **Clean Checkout Fields:** Removes unnecessary form clutter so customers can complete their orders quickly and easily.
- **WooCommerce HPOS Compatible:** Fully compatible with WooCommerce High-Performance Order Storage and modern block themes.
- **Self-Hosted Freedom:** No recurring monthly app fees for basic cart features—100% owned on your own WordPress hosting.

## 🚀 Developer Setup & Local Testing

1. **Clone the repository:**
   ```bash
   git clone https://github.com/harunsekmen/apex-commerce-d2c-starter.git wp-content/plugins/apex-commerce-d2c-starter
   ```

2. **Activate the plugin:**
   ```bash
   wp plugin activate apex-commerce-d2c-starter
   ```

3. **Run local simulation tests:**
   ```bash
   node tests/run-e2e-test.js
   ```
